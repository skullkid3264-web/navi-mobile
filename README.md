# N.A.V.I. モバイル（Navigator of All Vital Information）

PCの音声アシスタント「N.A.V.I.」を、スマホから使うための専用アプリ。

- 🎤 スマホ内蔵の音声認識で話しかける（話し終わると自動で送信）
- 💬 PCのN.A.V.I.と同じ会話：確認 →「実行」と言う／ボタンを押す
- 🔊 返事の読み上げ
- 🔔 通知：朝のまとめ・期限・夕方の振り返り・相談リスト・承認待ちの目標
- 📣「ナビ」と呼びかけて使う（設定でオン／オフ）：画面を閉じていても「ナビ、今日のまとめ」で動き、声で返事して「実行しますか？」と聞く
- 🎤 1タップで話す：ホーム画面のウィジェット／アイコン長押しのメニュー／クイック設定のタイル
- 📅 予定：月のカレンダー（先月〜再来月の予定をPCから受け取って端末に保存。回線やPCにつながらなくても見られる）。日をタップすると、その日の予定が出ます。予定は文字で入力して追加・変更（✎）・削除（🗑・2回タップ）でき、つながっていないときは書き溜めに入って、つながると自動でPCに送られます（⏳は送信待ち）。PC側の予定が正で、Googleカレンダーへの反映はPCが行います
- 📝 書き溜め：つながらない場所で、メモ・Todo・予定・生徒メモ・日記・PCへの指示を書いておく。つながると自動で送る（指示だけは確認して実行）
- ⬆ アプリ内の「新しい版があります」ボタンで自動更新（依頼掲示板と同じ仕組み）

## しくみ

```
スマホアプリ ⇄ GAS（VoiceApi.gs）⇄ PCのN.A.V.I.
```

- 会話：アプリが GAS の受信箱に指示を置く → PCのN.A.V.I.が取りに来て処理 → 返事を GAS に置く → アプリが受け取る
- 通知：PCのN.A.V.I.が GAS に「お知らせ」を置く → アプリが15分おきに確かめて、Androidの通知を出す
  （Androidの省電力の仕様で、通知は最大15分ほど遅れることがあります）
- PCが切れていても、GAS側の「承認待ちの目標」は毎日17時ごろ通知されます（`setupVoiceNoticeTrigger` を1回実行）
- 生徒の名前は通知に入れません（件数のみ）

## 最初のセットアップ

1. この中身を GitHub の新しいリポジトリ（例：`navi-mobile`、公開）に置く
2. リポジトリの Settings → Secrets and variables → Actions に、依頼掲示板と同じ2つを登録
   - `KEYSTORE_BASE64`
   - `KEYSTORE_PASSWORD`
3. `main` に置くと自動でビルドされ、Releases に `NAVI-vN.apk` ができる
4. スマホで APK を開いてインストール（「提供元不明のアプリ」を許可）
5. スプレッドシート側：`VoiceApi.gs` と `VoiceMobile.html` を差し替え、新しいバージョンとしてデプロイ。
   GASエディタで `setupVoiceNoticeTrigger` を1回実行（PCが切れていても届く通知用）
6. PC側：`update.bat` で最新版に更新 → N.A.V.I.の「📱 スマホを登録」を開き、
   「📲 専用アプリの登録コード」の「コピー」を押す
7. スマホのアプリの最初の画面に、そのコードを貼り付けて「登録する」

## 補足

- 音声認識はAndroid標準のもの（Google）を使います。英語の生徒名は、カタカナで認識されることが多いので、
  N.A.V.I.の「名前・番号・クラスで呼ぶ」機能（○番、Aクラス全員）と合わせると確実です。
- 版の番号はビルドの通し番号です。更新のたびに自動で増えます。
- 署名鍵を変えると、上書き更新できなくなります。必ず同じ鍵を使ってください。

## 呼びかけ待ち（ウェイクワード）について

- Android標準の音声認識を繰り返し動かして「ナビ」を探す方式です（専用の呼びかけ検出ライブラリは使いません）。
  そのため、電池を使い、認識の開始音が鳴る機種があり、周りの会話の「ナビ」にも反応することがあります。
- アプリの画面を開いている間は、マイクを譲るため待機を止めます。閉じると再開します。
- 端末を再起動したあとは、アプリを一度開くと待機が再開します（Androidの制限のため）。
- 通知バーの「オフにする」でいつでも止められます。

## 読み上げの声を変える
設定（⚙）の「🗣 読み上げの声」で、声の種類・速さ・高さを変えられます。「▶ この声で試す」で試し聞き。
声の一覧は端末に入っている日本語の声です。増やしたいときは「➕ 声をふやす」から端末の「テキスト読み上げ」設定を開き、日本語の声データを追加してください（端末により名前や手順が違います）。

## 短い声（読み上げの代わりに、場面に合うひとこと）
- PCで「ボイス素材を作って」と言うか、`voice_clips.bat` を実行すると、PCのVOICEVOXが、場面ごとの短いセリフ（できたよ！／すごいすごい！／ゆっくり休んでね…など約50個）を作って、スマホに送ります。
- スマホは、設定の「短い声」で取り込みます（起動時と、しばらくごとに自動でも確認）。端末に保存するので、オフラインでも鳴ります。
- 「短い声だけ」：確認・完了・やめた・受け取り などは、読み上げの代わりに短い声だけ。「声のあとに読み上げも」「読み上げだけ」にも切り替えられます。素材がない場面は、これまで通り読み上げます。
- 自分で用意した素材（wav/mp3）も、PCの data/voice_clips/ に「場面名_数字.wav」（例：done_5.wav）で置いて「声の素材をスマホに送って」で使えます。
