# N.A.V.I. モバイル（Android）

PCの音声アシスタント「N.A.V.I.」を、スマホから使うための専用アプリ。

- 🎤 スマホ内蔵の音声認識で話しかける（話し終わると自動で送信）
- 💬 PCのN.A.V.I.と同じ会話：確認 →「実行」と言う／ボタンを押す
- 🔊 返事の読み上げ
- 🔔 通知：朝のまとめ・期限・夕方の振り返り・相談リスト・承認待ちの目標
- ⬆ アプリ内の「新しい版があります」ボタンで自動更新（依頼掲示板と同じ仕組み）

## しくみ

```
スマホアプリ ⇄ GAS（VoiceApi.gs）⇄ PCのN.A.V.I.
```

- 会話：アプリが GAS の受信箱に指示を置く → PCのN.A.V.I.が取りに来て処理 → 返事を GAS に置く → アプリが受け取る
- 通知：PCのN.A.V.I.が GAS に「お知らせ」を置く → アプリが15分おきに確かめて、Androidの通知を出す
  （Androidの省電力の仕様で、通知は最大15分ほど遅れることがあります）
- PCが切れていても、GAS側の「承認待ちの目標」は毎日17時ごろ通知されます（`setupVoiceNoticeTrigger` を1回実行）
- 生徒の名前は通知に入れません（件数のみ）

## 最初のセットアップ

1. この中身を GitHub の新しいリポジトリ（例：`navi-mobile`、公開）に置く
2. リポジトリの Settings → Secrets and variables → Actions に、依頼掲示板と同じ2つを登録
   - `KEYSTORE_BASE64`
   - `KEYSTORE_PASSWORD`
3. `main` に置くと自動でビルドされ、Releases に `NAVI-vN.apk` ができる
4. スマホで APK を開いてインストール（「提供元不明のアプリ」を許可）
5. スプレッドシート側：`VoiceApi.gs` と `VoiceMobile.html` を差し替え、新しいバージョンとしてデプロイ。
   GASエディタで `setupVoiceNoticeTrigger` を1回実行（PCが切れていても届く通知用）
6. PC側：`update.bat` で最新版に更新 → N.A.V.I.の「📱 スマホを登録」を開き、
   「📲 専用アプリの登録コード」の「コピー」を押す
7. スマホのアプリの最初の画面に、そのコードを貼り付けて「登録する」

## 補足

- 音声認識はAndroid標準のもの（Google）を使います。英語の生徒名は、カタカナで認識されることが多いので、
  N.A.V.I.の「名前・番号・クラスで呼ぶ」機能（○番、Aクラス全員）と合わせると確実です。
- 版の番号はビルドの通し番号です。更新のたびに自動で増えます。
- 署名鍵を変えると、上書き更新できなくなります。必ず同じ鍵を使ってください。
